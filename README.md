# 🇷🇺 Teste A1 de Russo

Quiz interativo com **10 perguntas** sobre o idioma russo (nível A1), feito em Python com [Streamlit](https://streamlit.io/).

## 🔗 Acesse o quiz

👉 https://russianquiza1.streamlit.app/

## 📖 Sobre o projeto

Criei esse quiz pra praticar russo enquanto aprendo Python. As perguntas são baseadas no PDF do curso de russo do site [Time to Speak Russian](https://timetospeakrussian.com/).

Cada pergunta é uma frase com uma lacuna, e você escolhe entre **2 alternativas** a que completa corretamente. Os assuntos cobertos são:

- Vocabulário básico (ex.: *осень*, *девушка*)
- Nacionalidades (ex.: *немец*)
- Verbos de uso comum (ex.: *понимаете*, *хочу*)
- Expressões de necessidade (ex.: *нужно*, *надо*)
- Advérbios e expressões (ex.: *по-русски*, *холодно*, *очень*)

## ⚙️ Como funciona

1. Responda às 10 perguntas (só dá pra finalizar com todas respondidas).
2. Clique em **Finalizar Quiz**.
3. O quiz mostra, pergunta por pergunta, se você acertou ou errou, e qual era a resposta certa.
4. No final aparece o resultado geral. Pra ser aprovado, é preciso acertar **pelo menos 6 de 10**.
5. Clique em **Refazer Quiz** pra tentar de novo.

## 🛠️ Tecnologias usadas

- Python
- Streamlit

## ▶️ Como rodar na sua máquina

1. Baixe ou clone o repositório:

```bash
git clone https://github.com/Th1ag0-96/site-quiz-russo-a1.git
cd site-quiz-russo-a1
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Rode o quiz:

```bash
streamlit run QuizRussoA1.py
```

O navegador vai abrir sozinho com o quiz funcionando.

## 📁 Arquivos principais

- `QuizRussoA1.py`: código do quiz
- `requirements.txt`: bibliotecas necessárias
